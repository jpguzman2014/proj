# Asset and dependency manifest

Every image, icon and font this app serves, and where the licence comes from.
Kept so that "where did this asset come from?" always has an answer on file.

## Images

| Asset | Source | Licence |
|---|---|---|
| Clue art shown on every question | Generated at runtime by `src/media/generatedArt.ts` from each entry's own metadata | Original work in this repository |
| `public/icons/icon.svg` | Hand-authored in this repository | Original work in this repository |
| `public/icons/icon-180.png`, `icon-192.png`, `icon-512.png` | Generated by `scripts/make-icons.mjs`, which writes the PNG bytes directly | Original work in this repository |
| QR codes in party mode | Generated in the browser from the join URL | Original output; see the library below |

No game screenshots, cover art, character renders, promotional images or logos
are stored, bundled or served. Nothing was taken from an image search. There are
no photographs of people and no third-party illustrations.

## Fonts

None are bundled or fetched. The app uses the reader's own system font stack
(`system-ui` and platform fallbacks), so no webfont licence is involved.

## Emoji

Mode icons are emoji characters rendered by the reader's operating system font.
No emoji image files are shipped.

## Code dependencies that reach the browser

| Package | Purpose | Licence |
|---|---|---|
| react, react-dom | UI | MIT |
| qrcode-generator | Builds the party-mode QR code locally | MIT |

Build and test only: vite, @vitejs/plugin-react, typescript, esbuild (via vite).

## Game names and trademarks

Game titles, character names, studio and publisher names in `src/data/` are
trademarks of their respective owners. They appear as the subject of quiz
questions, which is nominative use: naming a work in order to ask about it. No
logo, wordmark or artwork belonging to any of them is reproduced.
