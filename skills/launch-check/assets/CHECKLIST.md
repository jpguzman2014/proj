# Launch Check

Status of the 19 pre-launch compliance items. Update as work lands; keep it in version
control so the audit state survives.

Legend: `[ ]` not done, `[x]` done and verified, `[?]` needs owner input, `[-]` not
applicable with the reason recorded.

## Accessibility

- [ ] **Colour contrast** — 4.5:1 body text, 3:1 large text and UI, including hover,
      placeholder, and disabled states
- [ ] **Alt text on images** — every `<img>` has `alt`; decorative use `alt=""`
- [ ] **Keyboard friendly forms** — full Tab traversal, visible focus, no traps, labels
      bound to inputs
- [ ] **Clear button labels** — accessible name says what happens; no bare icon buttons
- [ ] **General accessibility** — landmarks, heading order, `lang`, 200% zoom

## Legal pages

- [ ] **Privacy policy page** — real content, real processors named
- [ ] **Terms and conditions page**
- [ ] **Cookies policy** — every cookie tabulated
- [ ] **Refund policy** — published before payment is taken
- [ ] **Real business details** — legal entity, address, email, registration number

## Privacy and data

- [ ] **Cookie consent** — reject as easy as accept; nothing fires before consent
- [ ] **Tracking audit** — every third-party call inventoried and disclosed
- [ ] **Form consent** — separate, unticked, specific opt-in for marketing
- [ ] **Only collect necessary data** — surplus fields removed, retention set
- [ ] **Third-party embeds** — privacy modes or click-to-load, disclosed

## Honest content

- [ ] **Remove fake reviews** — including template placeholders
- [ ] **Remove unsupported claims** — evidence on file for every claim
- [ ] **Image copyright** — licence traceable for every asset and font
- [ ] **Check local laws** — jurisdictions in scope identified
